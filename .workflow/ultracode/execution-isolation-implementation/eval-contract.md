# Eval contract

## Goal
Prevent a conditional security specification from becoming an unreviewed or mock-qualified runtime.

## Success criteria
- Proposed mechanisms have alternatives, constraints, primary sources, residual risks, approval fields and explicit OPEN status.
- Every gate has an actionable qualification plan with positive controls and explicit missing evidence.
- Budget measurement artifact records no invented results or approved numerical limits.
- BG-01 inventories actual source and upstream disagreements; no fabricated result enum, schema or authority-bearing extension.
- Existing Spec 1, spec requirements/design/tasks, licensing, dependency lockfiles and user research inputs remain unchanged.
- Native qualification remains MISSING; no checkboxes are marked complete based on drafts.

## Integration surfaces
Spec 2 TASK-001–006 decision/report paths feed TASK-007. Spec 1 exports/schema agreement feed BG-01. No executable adapter or IPC contract is activated by this preparation.

## Downstream consumers
Core/worker owners approve IPC and contracts; security/operations owners approve isolation, credentials and persistence; core/operations owners approve measured budgets; parent reconciles all six before runtime work.

## Required checks
Baseline source inventory and real-export compile probe; existing seven scaffold tests; existing spec checker and nine sensitivity tests; diff/hash/JSON checks; independent integrated review. Later runtime completion additionally requires same-target RED/GREEN checkpoints, >=80% coverage, build/lint/full regression, native AC-05/06/08 and restore/release evidence.

## Deliverables
Six decision records; isolation, IPC, credential, restore, upstream-compatibility plans and unmeasured budget JSON; run evidence and truthful partial handoff.
User-approved additional deliverable: separate proposed Spec 1 prerequisite plan, without upstream implementation or spec amendments.

## Blocking conditions
No approved UD/BG records; missing real upstream API/schema; unapproved probe environment; unmeasured budgets; unverified independent observation; missing approval or retention values. None may be bypassed by adding a default, mock or generated approval.
