# Orchestration

## Parent critical path
Read brief and verify branch → verify SDK claims → draft requirements → integrate adversarial gate → conditional design → tasks → final audit.

## Packets
01-upstream-evaluation: read-only source dependency and measurement review.
02-requirements: read-only requirements counterexamples.
03-integrated: read-only design/task coverage and safety review.

## Delegation
One discovery sidecar; one staged review wave after its prerequisites. No write agents or recursive fan-out.

## Agents
Native collaboration, inherited model/effort; observed settings UNVERIFIED. Parent handles all external MCP/docs.

## Delegation limits
Three cumulative worker turns, zero follow-ups/replacements, at most two concurrent, one consolidated parent repair, 60-minute elapsed cap. Token usage unknown. Replan rather than silently expand limits.

## Wait points
Requirements QA gates design. Integrated review gates final reporting.

## Fallback
If an agent route becomes unavailable, parent performs bounded manual review and reports lack of independence. Unresolved product choices gate implementation, not honest conditional documentation.

## Verification order
Primary facts → requirements structure/QA → design/task traceability and graph → regression/scope → report.
